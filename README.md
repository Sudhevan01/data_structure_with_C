# 📘 Data Structures Lab Programs (Turbo C++ Version)

This repository contains my Data Structures lab programs written in **C language using Turbo C++ compiler**.

## 🖥️ Compiler Used
- Turbo C++ (DOS-based environment)
- C language
- Traditional header files like:
  - stdio.h
  - conio.h

## 📚 Programs Included

The repository contains programs related to:

A 1. Insertion and deleteion an element at
     desired position in an array
A 2. 2D array manipulation
A 3. Stack operations
A 4. Swap two variables using call by value and
     call by reference
A 5. Binary to decimal conversion
A 6. Queue operations
A 7. Quicksort
A 8. Linear search and binary search
B 1. Program to implement stack
B 2. program to convert infix arithmetic
     expression to postfix expression
B 3. Circular queue
B 4. Linked list
B 5. Insertion sort
B 6. Binary search tree and implement the tree raversal techniques of
      inorder,preorder and postorder

## ⚠️ Important Note

These programs are written specifically for **Turbo C++ environment**.  
Some functions like `clrscr()` and `getch()` may not work in modern compilers like:

- GCC
- VS Code (MinGW)
- CodeBlocks

If you want to run them in modern compilers, you may need to:
- Remove `conio.h`
- Remove `clrscr()` and `getch()`
- Make small modifications
