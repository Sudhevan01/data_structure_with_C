# 📘 Data Structures Lab Programs (Turbo C++ Version)

This repository contains my **Data Structures lab programs** written in **C language using the Turbo C++ compiler**.

---

## 🖥️ Compiler Used

- Turbo C++ (DOS-based environment)
- C Language
- Header Files:
  - `stdio.h`
  - `conio.h`

---

## 📚 Programs Included

### 🔹 Part A

1. Insertion and deletion of an element at a desired position in an array  
2. 2D array manipulation  
3. Stack operations  
4. Swap two variables using call by value and call by reference  
5. Binary to decimal conversion  
6. Queue operations  
7. Quick sort  
8. Linear search and binary search  

### 🔹 Part B

1. Stack implementation  
2. Infix to postfix expression conversion  
3. Circular queue  
4. Linked list  
5. Insertion sort  
6. Binary Search Tree (BST) with tree traversal techniques:
   - Inorder  
   - Preorder  
   - Postorder  

---

## ⚠️ Important Note

These programs are written specifically for the **Turbo C++ environment**.

Functions like:

- `clrscr()`
- `getch()`

may not work in modern compilers such as:

- GCC  
- VS Code (MinGW)  
- CodeBlocks  

If running in modern compilers, you may need to:
- Remove `conio.h`
- Remove `clrscr()` and `getch()`
- Make minor modifications
